Sistema para controle de chamados de suporte técnico.
O programa cadastra os clientes, os técnicos de campo e os problemas relatados
(desde lentidão na internet até falhas em equipamentos da rede). 
Ele aplica regras simples: impede que um técnico receba mais chamados do que o seu limite e só permite fechar um atendimento se houver um relatório explicando a solução.
Tudo isso construído com os conceitos de Orientação a Objetos exigidos no trabalho.
